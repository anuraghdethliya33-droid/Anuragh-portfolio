## ✨ Features & Aesthetics

- **🌸 Sakura Canvas Particle Engine**: Real-time 60fps HTML5 canvas rendering falling and swaying cherry blossom petals with interactive wind dynamics. Includes a toggle to pause/play particles.
- **✨ Custom Blossom Trailing Cursor**: Tracks pointer movement with a glowing center, gentle drifting petal trail, and celebratory petal bursts on click.
- **🤖 Integrated AI Chatbot**: Built-in Botpress conversational agent for instant visitor queries and interactive communication.
- **💎 Glassmorphic & Trending Aesthetic**: Frosted glass panels (`backdrop-blur-md bg-white/80`), pastel sakura palette, ambient glowing halos, and *Playfair Display* serif paired with *Plus Jakarta Sans*.
- **📱 Fully Responsive**: Custom mobile hamburger navigation drawer and adaptive grid systems.

## 🚀 Running Locally

```bash
# 1. Clone the repository
git clone https://github.com/Anuragh33/anuragh-portfolio.git
cd anuragh-portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```
